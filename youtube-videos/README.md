# Per-video workspaces

Codex creates a separate folder here when the creator supplies a new Psychology Facts title. Use `python3 scripts/youtube_agent.py init "TITLE"`; initialization is non-destructive and marks every drafting stage pending. No video is generated during installation.

Every workspace contains research/evidence, five hooks, the seven-part outline, English/Vietnamese scripts, voice-over text, an editorial retention review, an action-led storyboard and YouTube metadata. Root AGENTS.md and production/youtube/workflow.md define how the four automatic skills fill them in.

Paid APIs and YouTube publication are disabled by default. Do not commit credentials, downloaded personal data, dependency caches or fabricated research/analytics into these folders.
